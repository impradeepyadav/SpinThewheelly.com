นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 31 ตุลาคม 2026

ที่ Spin The Wheelly ความเป็นส่วนตัวของคุณมีความสำคัญต่อเรา หน้านี้อธิบายอย่างชัดเจนว่ามีการเก็บรวบรวมข้อมูลใดบ้างเมื่อคุณใช้เว็บไซต์ของเรา ข้อมูลเหล่านั้นถูกนำไปใช้อย่างไร และคุณมีทางเลือกอะไรบ้าง แกนหลักของวงล้อ — รายการ การหมุน รูปภาพ และผลลัพธ์ของคุณ — ยังคงอยู่ในเบราว์เซอร์ของคุณทั้งหมดและไม่เคยถูกส่งไปยังเซิร์ฟเวอร์ใด ๆ ข้อมูลเดียวที่เก็บรวบรวมมาจากพันธมิตรด้านโฆษณาและการวิเคราะห์ที่ช่วยให้เว็บไซต์ยังคงใช้งานฟรี

1. ข้อมูลที่เราเก็บรวบรวม

เราไม่เก็บรวบรวม จัดเก็บ หรือส่งต่อเนื้อหาใด ๆ ที่คุณพิมพ์ลงในวงล้อ ชื่อ ตัวเลือก รายการที่กำหนดเอง รูปภาพที่อัปโหลด และผลลัพธ์ทั้งหมดจะอยู่ในหน่วยความจำของเบราว์เซอร์ของคุณและไม่เคยถูกส่งไปยังเซิร์ฟเวอร์ใด ๆ

อย่างไรก็ตาม เว็บไซต์ใช้บริการของบุคคลที่สาม (การวิเคราะห์และโฆษณา) ที่อาจเก็บรวบรวมข้อมูลทางเทคนิคที่จำกัดโดยอัตโนมัติ เช่น:

  • ที่อยู่ IP (ใช้โดยเครือข่ายการวิเคราะห์และโฆษณาเพื่อกำหนดตำแหน่งโดยประมาณ)
  • ประเภทเบราว์เซอร์ ประเภทอุปกรณ์ ระบบปฏิบัติการ และภาษา
  • หน้าที่เยี่ยมชม เวลาที่ใช้ และ URL ที่อ้างอิง
  • รูปแบบการใช้งานทั่วไปและการมีปฏิสัมพันธ์กับเว็บไซต์
  • ตัวระบุคุกกี้ที่ใช้สำหรับการวิเคราะห์และโฆษณา

ข้อมูลนี้ใช้ในรูปแบบรวมเพื่อทำความเข้าใจว่ามีการใช้งานเว็บไซต์อย่างไร ปรับปรุงประสิทธิภาพ และแสดงโฆษณาที่เกี่ยวข้อง

2. การจัดเก็บข้อมูลภายในเครื่อง

สิ่งเดียวที่เราเก็บไว้บนอุปกรณ์ของคุณโดยตรงคือการตั้งค่าเล็ก ๆ ภายในเครื่อง: ตัวเลือกโหมดสว่างหรือมืดของคุณ ซึ่งบันทึกผ่าน API localStorage ของเบราว์เซอร์และยังคงอยู่ในคอมพิวเตอร์ของคุณทั้งหมด

  • สิ่งที่เก็บ: คีย์เดียวชื่อ theme ที่มีค่า light หรือ dark
  • ที่เก็บ: เฉพาะภายในเบราว์เซอร์ของคุณเท่านั้น
  • ส่งไปที่อื่นหรือไม่: ไม่ ไม่เคยออกจากอุปกรณ์ของคุณ
  • วิธีลบ: ล้างข้อมูลไซต์สำหรับ spinthewheelly.com ในเบราว์เซอร์ของคุณได้ทุกเมื่อ

เราไม่เก็บรายการ การหมุน ผลลัพธ์ รูปภาพ หรือสิ่งอื่นใดที่คุณพิมพ์ลงในวงล้อ

3. คุกกี้และเทคโนโลยีการติดตาม

เช่นเดียวกับเว็บไซต์ส่วนใหญ่ Spin The Wheelly ใช้คุกกี้และเทคโนโลยีที่คล้ายกัน (เช่น พิกเซลและเว็บบีคอน) คุกกี้เป็นไฟล์ข้อความขนาดเล็กที่จัดเก็บบนอุปกรณ์ของคุณซึ่งช่วยให้เว็บไซต์ทำงานได้อย่างถูกต้อง เข้าใจรูปแบบการใช้งาน และส่งมอบโฆษณา

เราใช้คุกกี้ในหมวดหมู่ต่อไปนี้:

  • คุกกี้ที่จำเป็นอย่างยิ่ง: จำเป็นสำหรับการทำงานที่ถูกต้องของเว็บไซต์ (ความปลอดภัย การนำทางพื้นฐาน การจดจำการตั้งค่าธีม) ไม่สามารถปิดใช้งานได้
  • คุกกี้เพื่อการวิเคราะห์: ช่วยให้เราเข้าใจว่าผู้เยี่ยมชมใช้เว็บไซต์อย่างไร — หน้าใดบ้างที่เยี่ยมชม ผู้ใช้มาถึงเว็บไซต์อย่างไร และมีปฏิสัมพันธ์อย่างไร เราใช้ Google Analytics เพื่อวัตถุประสงค์นี้
  • คุกกี้เพื่อการโฆษณา: ใช้โดยเครือข่ายโฆษณาบุคคลที่สามเพื่อส่งมอบโฆษณาที่อาจเกี่ยวข้องกับคุณและเพื่อวัดประสิทธิภาพของโฆษณา

ในกรณีที่กฎหมายที่บังคับใช้กำหนด (เช่น ภายใต้คำสั่ง ePrivacy ของสหภาพยุโรป) เราได้รับความยินยอมจากคุณก่อนวางคุกกี้ที่ไม่จำเป็น คุณสามารถจัดการหรือเพิกถอนความยินยอมได้ทุกเมื่อผ่านแบนเนอร์ความยินยอมคุกกี้หรือโดยการปรับการตั้งค่าเบราว์เซอร์ของคุณ โปรดทราบว่าการปิดใช้งานคุกกี้อาจส่งผลต่อฟังก์ชันบางอย่างของเว็บไซต์

4. Google Analytics

เราใช้ Google Analytics ซึ่งเป็นบริการวิเคราะห์เว็บที่ให้บริการโดย Google LLC ("Google") เพื่อวัดและวิเคราะห์ว่าผู้เยี่ยมชมใช้เว็บไซต์อย่างไร Google Analytics รวบรวมข้อมูล เช่น ที่อยู่ IP ประเภทเบราว์เซอร์ ข้อมูลอุปกรณ์ หน้าที่เยี่ยมชม เวลาที่ใช้ในหน้า และแหล่งที่มาของการอ้างอิง ข้อมูลนี้ใช้เพื่อปรับปรุงเว็บไซต์และทำความเข้าใจพฤติกรรมของผู้ใช้

Google Analytics อาจตั้งค่าคุกกี้บนอุปกรณ์ของคุณและอาจถ่ายโอนข้อมูลไปยังเซิร์ฟเวอร์ที่ตั้งอยู่นอกประเทศที่คุณอาศัยอยู่ Google ประมวลผลข้อมูลนี้ในนามของเราและผูกพันตามสัญญาที่จะปกป้องข้อมูลดังกล่าว สำหรับข้อมูลเพิ่มเติมเกี่ยวกับวิธีที่ Google รวบรวมและประมวลผลข้อมูล โปรดเยี่ยมชม วิธีที่ Google ใช้ข้อมูลจากไซต์หรือแอปที่ใช้บริการของเรา

คุณสามารถเลือกไม่รับการติดตามของ Google Analytics ได้โดยการติดตั้ง โปรแกรมเสริมการเลือกไม่รับ Google Analytics สำหรับเบราว์เซอร์ หรือโดยการปรับการตั้งค่า Google Ads ของคุณ โปรดทราบว่าการเลือกไม่รับไม่ได้ป้องกันการรวบรวมข้อมูลทั้งหมดโดยบุคคลที่สามรายอื่น

5. โฆษณาบุคคลที่สามและลิงก์พันธมิตร

เว็บไซต์แสดงโฆษณาและอาจมีลิงก์พันธมิตร ซึ่งจัดหาโดยเครือข่ายโฆษณาบุคคลที่สามและพันธมิตรด้านพันธมิตร เมื่อคุณคลิกที่ลิงก์พันธมิตรและทำการซื้อ เราอาจได้รับค่าคอมมิชชันโดยไม่มีค่าใช้จ่ายเพิ่มเติมสำหรับคุณ สิ่งนี้ช่วยให้เราเว็บไซต์ยังคงใช้ฟรี

เครือข่ายโฆษณาบุคคลที่สามและพันธมิตรอาจใช้คุกกี้ เว็บบีคอน หรือเทคโนโลยีที่คล้ายกันเพื่อเก็บรวบรวมข้อมูลเกี่ยวกับการเยี่ยมชมเว็บไซต์นี้และเว็บไซต์อื่น ๆ ของคุณ เพื่อมอบโฆษณาที่เกี่ยวข้อง เราไม่ควบคุมข้อมูลที่เก็บรวบรวมโดยบุคคลที่สามเหล่านี้ และแนวปฏิบัติของพวกเขาอยู่ภายใต้นโยบายความเป็นส่วนตัวของตนเอง เราขอแนะนำให้คุณตรวจสอบนโยบายของพวกเขา รวมถึง:

  • นโยบายความเป็นส่วนตัวของ Google (สำหรับ Google Ads และ Analytics)
  • การตั้งค่าโฆษณา Google (เพื่อเลือกไม่รับโฆษณา Google ที่ปรับแต่งเฉพาะบุคคล)
  • Digital Advertising Alliance Opt-Out (สำหรับผู้ใช้ในสหรัฐอเมริกา)
  • Your Online Choices (สำหรับผู้ใช้ในสหภาพยุโรป)

6. บริการของบุคคลที่สาม

เราจำกัดบริการของบุคคลที่สามให้น้อยที่สุด ปัจจุบันเราใช้:

  • Google Fonts — เพื่อแสดงแบบอักษร Inter และ Noto Sans Thai เบราว์เซอร์ของคุณส่งคำขอไปยัง fonts.googleapis.com เพื่อดึงไฟล์แบบอักษร และ Google อาจเห็นที่อยู่ IP ของคุณเป็นส่วนหนึ่งของคำขอดังกล่าว ดูนโยบายความเป็นส่วนตัวของ Google
  • Google Analytics — สำหรับการวิเคราะห์การเข้าชม (ดูส่วนที่ 4 ด้านบน)
  • เครือข่ายโฆษณาบุคคลที่สามและพันธมิตร — สำหรับโฆษณาและการสร้างรายได้ (ดูส่วนที่ 5 ด้านบน)

7. สิทธิความเป็นส่วนตัวของคุณ (GDPR / CCPA และกฎหมายอื่น ๆ)

ขึ้นอยู่กับตำแหน่งที่ตั้งของคุณ คุณอาจมีสิทธิบางประการเกี่ยวกับข้อมูลส่วนบุคคลของคุณภายใต้กฎหมายความเป็นส่วนตัวที่บังคับใช้ รวมถึงกฎระเบียบคุ้มครองข้อมูลทั่วไปของสหภาพยุโรป ("GDPR") GDPR ของสหราชอาณาจักร และพระราชบัญญัติความเป็นส่วนตัวของผู้บริโภคแคลิฟอร์เนีย ("CCPA") ภายใต้กฎหมายที่บังคับใช้ คุณอาจมีสิทธิ์:

  • เข้าถึงข้อมูลส่วนบุคคลที่เก็บไว้เกี่ยวกับคุณ
  • ขอแก้ไขข้อมูลส่วนบุคคลที่ไม่ถูกต้อง
  • ขอลบข้อมูลส่วนบุคคลของคุณ
  • คัดค้านหรือจำกัดการประมวลผลข้อมูลส่วนบุคคลบางอย่างของคุณ
  • ขอความสามารถในการพกพาข้อมูลส่วนบุคคลของคุณ
  • เพิกถอนความยินยอมได้ทุกเมื่อเมื่อการประมวลผลขึ้นอยู่กับความยินยอม
  • เลือกไม่รับ "การขาย" หรือ "การแบ่งปัน"ข้อมูลส่วนบุคคล (ตามที่กำหนดใน CCPA)
  • ไม่ถูกเลือกปฏิบัติเนื่องจากการใช้สิทธิความเป็นส่วนตัวของคุณ

เพื่อใช้สิทธิใด ๆ เหล่านี้ โปรดติดต่อเรา เราจะตอบกลับคำขอที่ตรวจสอบแล้วภายในกรอบเวลาที่กฎหมายที่บังคับใช้กำหนด โปรดทราบว่าเนื่องจากตัววงล้อเองไม่เคยส่งรายการหรือผลลัพธ์ของคุณ คำขอส่วนใหญ่ที่เกี่ยวข้องกับข้อมูลเหล่านั้นจะได้รับการตอบสนองโดยอัตโนมัติ — ข้อมูลเหล่านั้นไม่เคยออกจากอุปกรณ์ของคุณ

8. ความเป็นส่วนตัวของเด็ก

วงล้อเป็นเครื่องมือง่าย ๆ ที่ปลอดภัย เหมาะสำหรับทุกวัย รวมถึงเด็กอายุต่ำกว่า 13 ปี เนื่องจากเนื้อหาวงล้อไม่เคยออกจากอุปกรณ์ของคุณ เราจึงไม่เก็บรวบรวมข้อมูลส่วนบุคคลจากเด็กผ่านตัววงล้อเอง

อย่างไรก็ตาม พันธมิตรด้านการวิเคราะห์และโฆษณาบุคคลที่สามอาจเก็บรวบรวมข้อมูลทางเทคนิคที่จำกัด (เช่น ที่อยู่ IP และตัวระบุคุกกี้) ตามที่อธิบายไว้ในส่วนที่ 3–5 ผู้ปกครองและครูที่ใช้เว็บไซต์กับเด็กควรทราบเรื่องนี้ เราไม่เก็บรวบรวมข้อมูลส่วนบุคคลจากเด็กอายุต่ำกว่า 16 ปีโดยเจตนา หากคุณเป็นผู้ปกครองหรือผู้ดูแลและเชื่อว่าเด็กได้ส่งข้อมูลส่วนบุคคลให้เรา โปรดติดต่อเราเพื่อให้เราสามารถดำเนินการที่เหมาะสมได้

9. ความปลอดภัยของข้อมูล

ฟังก์ชันหลักของวงล้อ — การสร้างตัวเลขสุ่ม การแสดงผลวงล้อ การจัดการรูปภาพ และการคำนวณผลลัพธ์ — ทำงานทั้งหมดในเบราว์เซอร์ของคุณโดยใช้ API เว็บมาตรฐานที่ผ่านการตรวจสอบอย่างดี:

  • crypto.getRandomValues() สำหรับความสุ่มเชิงเข้ารหัสที่ปลอดภัย
  • API Canvas และ SVG สำหรับการแสดงผล
  • API FileReader สำหรับการอัปโหลดรูปภาพ (เก็บไว้ภายในเครื่อง)
  • API Web Audio สำหรับเอฟเฟกต์เสียง
  • API SpeechSynthesis สำหรับการแปลงข้อความเป็นเสียง

เนื่องจากเนื้อหาวงล้อที่คุณป้อนไม่เคยออกจากอุปกรณ์ของคุณ จึงไม่มีที่เก็บข้อมูลฝั่งเซิร์ฟเวอร์ของข้อมูลดังกล่าวที่จะถูกละเมิดได้ ข้อมูลที่ส่งไปยังพันธมิตรด้านการวิเคราะห์และโฆษณาบุคคลที่สามจะถูกเข้ารหัสระหว่างการส่ง (HTTPS) และจัดการตามมาตรฐานความปลอดภัยของตนเอง

10. การเปลี่ยนแปลงนโยบายนี้

เราอาจอัปเดตนโยบายความเป็นส่วนตัวนี้เป็นครั้งคราวเพื่อสะท้อนการเปลี่ยนแปลงของเว็บไซต์ พันธมิตร หรือกฎหมายที่บังคับใช้ เมื่อเราทำเช่นนั้น เราจะอัปเดตวันที่ "อัปเดตล่าสุด" ที่ด้านบนของหน้านี้ การเปลี่ยนแปลงที่สำคัญจะประกาศอย่างชัดเจนบนหน้านี้ก่อนมีผลบังคับใช้
