隐私政策

最后更新日期：2026 年 10 月 31 日

在 Spin The Wheelly，我们非常重视您的隐私。本页面详细说明了您使用我们网站时会收集哪些信息、如何使用这些信息，以及您拥有哪些选择。转盘的核心 — 您的条目、旋转、图像和结果 — 完全保留在您的浏览器中，绝不会发送到任何服务器。收集的唯一数据来自帮助我们保持网站免费使用的广告和分析合作伙伴。

1. 我们收集的信息

我们不收集、存储或传输您输入转盘中的任何内容。 名称、选项、自定义条目、上传的图像和结果全部保留在您浏览器的内存中，绝不会发送到任何服务器。

但是，本网站使用第三方服务（分析和广告），可能会自动收集有限的技术信息，例如：

  • IP 地址（由分析和广告网络用于确定大致位置）
  • 浏览器类型、设备类型、操作系统和语言
  • 访问的页面、停留时间和来源 URL
  • 一般使用模式及与网站的互动
  • 用于分析和广告的 Cookie 标识符

这些信息以汇总方式用于了解网站的使用情况、改进其性能并展示相关广告。

2. 本地存储

我们直接在您设备上存储的唯一内容是一个小型本地偏好设置：您的浅色或深色模式选择。该设置通过浏览器的 localStorage API 保存，完全保留在您的计算机上。

  • 存储的内容：一个名为 theme 的键，值为 light 或 dark。
  • 存储的位置：仅在您的浏览器中本地存储。
  • 是否会发送到某处：不会。它绝不会离开您的设备。
  • 如何删除：随时在浏览器中清除 spinthewheelly.com 的网站数据。

我们不会存储您的条目、旋转、结果、图像或您输入转盘的任何其他内容。

3. Cookie 和跟踪技术

与大多数网站一样，Spin The Wheelly 使用 Cookie 和类似技术（如像素和网络信标）。Cookie 是存储在您设备上的小型文本文件，可帮助网站正常运行、了解使用模式并投放广告。

我们使用以下类别的 Cookie：

  • 严格必要的 Cookie：网站正常运行所必需的（安全性、基本导航、记住您的主题偏好）。这些无法禁用。
  • 分析 Cookie：帮助我们了解访客如何使用网站 — 访问哪些页面、用户如何到达以及如何互动。我们为此使用 Google Analytics。
  • 广告 Cookie：由第三方广告网络使用，用于投放可能与您相关的广告并衡量广告效果。

在适用法律要求的情况下（例如根据欧盟 ePrivacy 指令），我们在您设备上放置非必要 Cookie 之前会获得您的同意。您可以随时通过 Cookie 同意横幅或调整浏览器设置来管理或撤回您的同意。请注意，禁用 Cookie 可能会影响网站的某些功能。

4. Google Analytics

我们使用 Google Analytics（由 Google LLC 提供的网络分析服务，以下简称"Google"）来衡量和分析访客如何使用网站。Google Analytics 收集您的 IP 地址、浏览器类型、设备信息、访问的页面、在页面上花费的时间和来源等信息。此数据用于改进网站并了解用户行为。

Google Analytics 可能会在您的设备上设置 Cookie，并可能将数据传输到您居住国以外的服务器。Google 代表我们处理此数据，并受合同约束予以保护。有关 Google 如何收集和处理数据的更多信息，请访问 Google 如何使用使用我们服务的网站或应用中的信息。

您可以通过安装 Google Analytics 选择退出浏览器插件或调整 Google Ads 设置来选择退出 Google Analytics 跟踪。请注意，选择退出并不能阻止其他第三方的所有数据收集。

5. 第三方广告和联盟链接

本网站展示广告，可能包含联盟链接。这些由第三方广告网络和联盟合作伙伴提供。当您点击联盟链接并进行购买时，我们可能会赚取佣金，而您无需支付额外费用。这有助于我们保持网站免费。

第三方广告网络和联盟合作伙伴可能会使用 Cookie、网络信标或类似技术来收集有关您访问本网站和其他网站的信息，以便投放相关广告。我们不控制这些第三方收集的数据，其做法受其自身隐私政策的约束。我们建议您查看他们的政策，包括：

  • Google 隐私权政策（适用于 Google Ads 和 Analytics）
  • Google 广告设置（用于选择退出个性化 Google 广告）
  • 数字广告联盟选择退出（美国用户）
  • Your Online Choices（欧盟用户）

6. 第三方服务

我们将第三方服务保持在最低限度。目前，我们使用：

  • Google Fonts — 用于显示 Inter 字体。您的浏览器会向 fonts.googleapis.com 发出请求以获取字体文件，Google 可能会看到您的 IP 地址作为该请求的一部分。请参阅 Google 隐私权政策。
  • Google Analytics — 用于流量分析（请参阅上文第 4 节）。
  • 第三方广告网络和联盟合作伙伴 — 用于广告和变现（请参阅上文第 5 节）。

7. 您的隐私权（GDPR / CCPA 和其他法律）

根据您的所在地，您可能享有适用隐私法（包括欧盟《通用数据保护条例》（"GDPR"）、英国 GDPR 和《加州消费者隐私法》（"CCPA"））下关于您个人数据的特定权利。在适用法律允许的范围内，您可能有权：

  • 访问我们持有的关于您的个人数据。
  • 要求更正不准确的个人数据。
  • 要求删除您的个人数据。
  • 反对或限制对您个人数据的某些处理。
  • 要求可移植性您的个人数据。
  • 撤回同意在处理基于同意的情况下随时撤回。
  • 选择退出个人信息的"出售"或"共享"（根据 CCPA 定义）。
  • 不因行使隐私权而受到歧视。

要行使任何这些权利，请与我们联系。我们将在适用法律要求的时间范围内回应经过验证的请求。请注意，由于转盘本身从不传输您的条目或结果，有关这些数据的大多数请求都会自动得到满足 — 它们根本不会离开您的设备。

8. 儿童隐私

转盘是一个简单、安全的工具，适合所有年龄段，包括 13 岁以下的儿童。由于转盘内容绝不会离开您的设备，我们不会通过转盘本身从儿童那里收集任何个人信息。

但是，第三方分析和广告合作伙伴可能会收集有限的技术数据（例如 IP 地址和 Cookie 标识符），如第 3-5 节所述。与儿童一起使用本网站的父母和老师应了解这一点。我们不会故意直接收集 16 岁以下儿童的个人信息。如果您是父母或监护人，并认为儿童向我们提交了个人信息，请与我们联系，以便我们采取适当措施。

9. 数据安全

转盘的核心功能 — 随机数生成、转盘渲染、图像处理和结果计算 — 完全在您的浏览器中使用标准且经过充分审查的 Web API 运行：

  • crypto.getRandomValues() 用于加密安全的随机性
  • Canvas 和 SVG API 用于渲染
  • FileReader API 用于图像上传（保留在本地）
  • Web Audio API 用于音效
  • SpeechSynthesis API 用于文本转语音

由于您输入的转盘内容绝不会离开您的设备，因此不存在可被入侵的服务器端数据存储。传输给第三方分析和广告合作伙伴的数据在传输过程中已加密（HTTPS），并根据其自身的安全标准进行处理。

10. 对本政策的修改

我们可能会不时更新本隐私政策，以反映网站、其合作伙伴或适用法律的变化。当我们这样做时，我们会更新本页面顶部的"最后更新日期"。重大变更将在生效前在本页面上明确公布。
